# 🔐 Gerador de Senhas Aleatórias

Gerador de senhas aleatórias desenvolvido com **HTML5, CSS3 e JavaScript**, criado como um projeto prático para estudos de desenvolvimento web e construção de portfólio.

A aplicação permite gerar uma senha aleatória de 14 caracteres e copiá-la para a área de transferência através de um botão de cópia.

## ✨ Funcionalidades

- 🎲 Geração de senhas aleatórias
- 🔐 Senhas com 14 caracteres
- 🔤 Letras maiúsculas e minúsculas
- 🔢 Números
- 🔣 Caracteres especiais
- 📋 Cópia da senha para a área de transferência
- 🔔 Feedback visual após a cópia
- 🖱️ Efeitos de interação nos elementos
- 🎨 Interface simples e intuitiva

---

## 🛠️ Tecnologias utilizadas

### HTML5

Utilizado para criar a estrutura da aplicação.

### CSS3

Utilizado para estilização, layout, efeitos visuais e organização dos elementos.

### JavaScript

Utilizado para implementar a lógica de geração das senhas, manipulação do DOM, eventos e funcionalidade de cópia.

### Font Awesome

Utilizado para o ícone de cópia presente na interface.
